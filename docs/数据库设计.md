# 数据库设计（Supabase PostgreSQL）

SQL 文件：

- `supabase/migrations/202611230001_schema.sql`：表、约束、索引、触发器、新用户触发器
- `supabase/migrations/202611230002_rls.sql`：RLS、Storage 私有桶与策略、Realtime publication
- `supabase/migrations/202611230003_seed.sql`：20 主分类、作品、角色
- `supabase/migrations/202611230004_grants.sql`：public 表级 GRANT；Supabase 不会自动给 `anon` / `authenticated` 授权，缺这一步登录后所有查询都会 `permission denied`

---

## 1. 关系概览

```text
auth.users 1 ── 1 profiles
     │
     ├── 1:N products (owner_id)
     │        ├── 1:1 collections (per product)
     │        ├── 1:1 wishlist (per product)
     │        ├── 1:N board_assignments (per board_key)
     │        └── 1:N product_images (cover/highres)
     │
     ├── 1:N board_categories
     ├── 1:1 user_settings
     └── 1:N backup_logs

works 1 ── N characters
main_categories (global, 20 rows)
```

## 2. 表字段

### products

| 字段 | 类型 | 说明 |
|---|---|---|
| owner_id | uuid | 用户，RLS |
| id | text | 原始 ID 或站内新增 `U-...`，与 owner 联合主键 |
| name | text | 名称 |
| category / category_label | text | 原分类枚举/中文 |
| series | text | 系列 |
| work_id / character_id | text | 作品/角色，外键 |
| version | text | 商品版本 |
| price | numeric | 原始标价（人民币数字） |
| price_text | text | 原始价格文字（赠品/满赠等） |
| release_date | text | 发售日期（保持原字符串） |
| product_code | text | 商品编号 |
| image | jsonb | 合集图路径 + 红框坐标 + 尺寸 + thumb/sharp |
| folder | text | 来源文件夹 |
| verification_status | text | 原核实状态 |
| duplicate_group | text | 原同名候选 |
| notes | text | 备注/描述 |
| main_category / main_category_key | text | 20 主分类 |
| board / board_key | text | 联动/满赠 |
| classification_* | text/int | 原分类核对字段 |
| variety | text | 品种 |
| market_price | numeric | 市场价格（独立） |
| payload | jsonb | 完整商品 JSON（所有原字段 + 扩展字段） |
| is_user_created | boolean | 是否站内新增 |
| revision | int | 乐观锁版本 |
| created_at / updated_at | timestamptz | 时间 |

> `payload` 是完整字段的兜底；列字段是 `payload` 的可查询镜像。客户端读取时以列字段覆盖 payload 中的同名字段，保证编辑后一致。

### collections

| 字段 | 说明 |
|---|---|
| owner_id, product_id | 联合主键，外键到 products，商品删除级联 |
| quantity | ≥1 |
| purchase_price | 实际购买价（独立于市场价） |
| purchase_date | 购买日期 |
| note | 个人备注 |
| revision / timestamps | 冲突与审计 |

### wishlist

`(owner_id, product_id)` 主键，商品删除级联。

### board_categories

| 字段 | 说明 |
|---|---|
| owner_id, id | 联合主键；保留 V4 的 `gift_badge` / `c_xxx` ID |
| work_id, character_id | 外键 |
| board_key | collab / gift |
| name | 1–20 字 |
| sort_order | 导航顺序 |
| is_default | 是否默认满赠四类（仅标记，可删除） |
| revision | 冲突 |

### board_assignments

`(owner_id, product_id, board_key)` 主键；`category_id` 外键到 `board_categories(owner_id,id)`，`ON DELETE CASCADE`。没有记录即“未分类”。触发器校验商品与分类同板块。

### product_images

| 字段 | 说明 |
|---|---|
| id uuid | 主键 |
| owner_id, product_id | 外键，商品删除级联 |
| kind | cover / highres，唯一 `(owner,product,kind)` |
| storage_path / thumb_path | Storage 路径 |
| file_name / mime_type / size_bytes / width / height | 元数据 |
| revision | 冲突 |

### user_settings

`settings jsonb` 保存：

```json
{
  "defaultsInitialized": true,
  "migration": {
    "version": 1,
    "initial": true,
    "source": "local-v4",
    "migratedAt": "2026-11-23T...",
    "counts": { "products": 1537, "collections": 2, "categories": 4 }
  },
  "lastBackupAt": "2026-11-23T..."
}
```

### main_categories / works / characters

公开只读。20 个主分类的 order 与 V4 完全一致：

`badge, laser_ticket, poster, folder, hanging_picture, coaster_set, paper, gift_box, practical, standee, mahjong, decorative_painting, keychain, acrylic, plush, art_card, collection_card, memorial_card, handwritten_letter, small_card`

## 3. 触发器

| 触发器 | 作用 |
|---|---|
| `handle_new_user` on auth.users | 创建 profiles + user_settings |
| `bump_revision` | 更新时 `revision=old+1`, `updated_at=now()` |
| `set_updated_at` | profiles 更新时间 |
| `validate_board_assignment` | 商品/分类必须同板块且存在 |

`revision` 用于前端：

```sql
update products
set name = $1
where owner_id = auth.uid() and id = $2 and revision = $3
returning *;
```

返回 0 行 → 客户端提示冲突并提供“保留云端/覆盖”选择。

## 4. RLS 策略

所有私人表统一模式：

```sql
using ((select auth.uid()) = owner_id)
with check ((select auth.uid()) = owner_id)
```

`main_categories/works/characters`：

```sql
for select to anon, authenticated using (true)
```

Storage：

```sql
bucket_id = 'product-images'
and (storage.foldername(name))[1] = (select auth.uid()::text)
```

覆盖 select/insert/update/delete。桶为 private，文件上限 12MB，只允许 jpeg/png/webp/avif。

## 5. 索引

- `products(owner_id, board_key)`
- `products(owner_id, main_category_key)`
- `products(owner_id, updated_at desc)`
- `collections(owner_id)`
- `wishlist(owner_id)`
- `board_categories(owner_id, board_key, sort_order)`
- `board_assignments(owner_id, category_id)`
- `product_images(owner_id, product_id)`
- `backup_logs(owner_id, created_at desc)`

1537 条规模下，主要靠 owner_id 索引与前端内存筛选；不需要全文索引。

## 6. 查询示例

```sql
-- 当前用户商品数
select count(*) from public.products where owner_id = auth.uid();

-- 20 主分类顺序
select key, label, sort_order from public.main_categories order by sort_order;

-- 某商品收藏与购买信息
select p.id, p.name, p.market_price, c.quantity, c.purchase_price, c.purchase_date, c.note
from public.products p
left join public.collections c on c.owner_id = p.owner_id and c.product_id = p.id
where p.owner_id = auth.uid() and p.id = 'B01-001';

-- 联动分类计数
select bc.name, count(ba.product_id) as cnt
from public.board_categories bc
left join public.board_assignments ba
  on ba.owner_id = bc.owner_id and ba.category_id = bc.id
where bc.owner_id = auth.uid() and bc.board_key = 'collab'
group by bc.id, bc.name, bc.sort_order
order by bc.sort_order;
```

## 7. 数据完整性

- 商品 ID 在同一用户内唯一；不同用户可拥有相同原始 ID。
- 收藏/愿望只能引用自己的商品（复合外键 `(owner_id,product_id)`）。
- 删除分类 → 归属级联删除，商品/收藏/愿望保留。
- 删除商品 → 收藏/愿望/归属/图片记录级联删除。
- 删除用户（auth.users）→ 所有私人数据级联删除。
- 20 主分类不可被前端写；没有 insert/update/delete 策略。
- `board_assignments` 的触发器保证不会把商品归到其他板块的分类。

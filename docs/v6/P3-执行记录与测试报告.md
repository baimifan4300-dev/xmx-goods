# P3 执行记录与测试报告（书籍模块）

> 状态：P3 本地代码与测试完成；云端 V6 实机待 Migration。
> 时间：2026-11-24。

## 1. 已完成

### 书籍类型

- 默认 5 类：漫画/小说/画集/设定集/其他；
- 类型管理弹窗：新增、改名、删除；
- 有书籍使用该类型时禁止删除（后端检查）。

### 套书

- 新建/编辑套书；
- 字段：书名、类型、语言、出版社、版次、装帧、总卷数、说明；
- 删除套书前检查卷数，有卷时禁止删除；
- 套书详情显示应有卷数/已拥有/完成率/缺卷。

### 单本/卷

- 单本可不选套书，`set_id=null`；
- 套书下逐卷新增；
- 字段：书名、作者、编绘、出版社、语言、版次、装帧、卷标签、卷号、ISBN、状态、市场价、市场价日期、购买价、购买日期、渠道、备注；
- 不同语言/出版社/版次/装帧分别保存，不合并；
- 删除书籍前检查订单关联，有关联时禁止；
- 书籍状态使用统一 `status_definitions`。

### 页面

- 主导航新增「书籍收藏」；
- 书籍页：套书卡片 + 全部书籍卡片 + 类型/状态筛选 + 搜索；
- 套书详情、书籍详情、书籍编辑、套书编辑、类型管理弹窗；
- 本地预览下页面可打开，书籍为空时显示空状态。

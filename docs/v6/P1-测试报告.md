## 3. 本轮发现并修复的异常

| # | 异常 | 处理 |
|---:|---|---|
| 1 | `payment_records` 的列内联 check 自动命名与显式约束同名，PG 报 `constraint already exists` | 去掉列内联 check，只保留显式命名约束 |
| 2 | PGlite 的 `date` 返回 Date 对象，测试直接比字符串失败 | 查询改为 `market_price_date::text` |
| 3 | `series` 回填用 `select distinct owner_id, gen_random_uuid(), ...`，UUID 使 distinct 失效，会重复插入 | 改为 `group by owner_id, btrim(series)` + `not exists` |
| 4 | `v_owned_counts` 自连接 collections，sum 可能重复 | 改为直接 `sum(c.quantity)` |
| 5 | `v_collection_items` 书籍封面回退成 `cover_image_id::text`（UUID，不是路径） | 只用 `item_images.storage_path` |
| 6 | `works/characters` 有 delete 策略但没有 DELETE grant | 补 `grant ... delete` |

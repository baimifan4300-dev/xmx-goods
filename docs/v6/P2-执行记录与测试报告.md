# P2 执行记录与测试报告

> 状态：P2 谷子模块基础功能完成（云端 V6 实机验收待 Migration 后）。
> 时间：2026-11-24。

## 1. 已完成

### 作品 / 角色

- 首页新增「管理作品/角色」入口；
- 新增作品、编辑作品名、删除作品（软删除 + 关联检查）；
- 新增角色（必须选作品）、编辑角色名、删除角色（有商品则阻止）；
- 作品/角色变更后刷新云端快照，其他设备通过 Realtime/聚焦刷新同步；
- 内置 `gyly/xmx` 可改名，但不可删除。

### 全图鉴联动

- 商品列表真正按 `workId + characterId` 过滤；
- 切换作品后角色列表来自该作品；
- 切换角色后数量、分页、分类筛选、搜索重新计算；
- 首页统计、收藏网格、愿望网格、收藏进度均按当前角色统计；
- 当前作品/角色被删除时自动回退到同作品第一个角色或首页。

### 分类管理

- 20 个内置主分类支持改名、上/下移排序；
- 自定义主分类支持新增、改名、排序、删除；
- 删除自定义分类前统计商品数量：
  - 有商品 → 弹出目标分类选择，批量重归类后再软删除；
  - 无商品 → 确认后软删除；
- 新分类进入商品新增/编辑、导航筛选、分类进度、商品详情标签；
- 联动/满赠独立板块保持原逻辑，不混用。

### 系列清单

- 新建系列（绑定当前作品/角色）；
- 手工添加官方款清单项；
- 关联已有商品到系列；
- 清单项状态可改（写 `collections.statusId`）；
- 计算已拥有/清单总数/完成率；
- 删除清单项/系列（有清单项时阻止删系列）；
- 收藏首页/全图鉴/系列清单共用同一商品状态。

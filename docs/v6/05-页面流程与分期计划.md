# 05 · 页面结构、操作流程与分期计划

## 1. 导航结构

保留 V5 顶部品牌、粉色视觉、卡片和弹窗风格；主导航从 5 项扩展为：

```text
收藏首页 | 谷子图鉴 | 书籍收藏 | 待补尾款 | 报告 | 更多
```

「更多」包含：成就徽章、智能搜索、回收站、分类管理、状态管理、自定义字段、地点管理、备份恢复、账户。

移动端：

- 顶部保留品牌 + 账户；
- 主导航折叠为底部 5 个 Tab：首页 / 谷子 / 书籍 / 待补 / 更多；
- 管理类页面从「更多」进入；
- 表格改为卡片列表，筛选栏可横向滚动。

## 3. 关键操作流程

### 3.1 新增作品/角色

```text
收藏首页 → 作品与角色 → 新增作品
  → 输入作品名 → 保存
  → 在该作品下新增角色 → 选择作品 → 输入角色名/主题色 → 保存
  → 角色卡片出现；点击进入谷子图鉴
```

规则：

- 新增角色必须选作品；
- 作品/角色保存后刷新 `store.works`，首页和全图鉴共用；
- 删除角色前查 `products.character_id`，有商品则阻止并显示数量；
- 删除作品前查角色和商品，有则阻止；
- 内置 `gyly/xmx` 可编辑名称/主题，但不可删除。

### 3.2 全图鉴作品/角色联动

```text
选择作品 → 角色下拉只显示该作品角色
  → 选择角色 → 商品列表按 work_id + character_id 过滤
  → 数量、分页、分类筛选、搜索全部重算
```

状态一致性：

- `state.currentWork/currentChar` 和 URL `#/goods/w/:workId/c/:charId` 是唯一来源；
- 首页角色卡点击 = 设置同一路由，不另存首页状态；
- 当前角色被删除 → 自动跳到该作品第一个角色；作品无角色 → 显示空状态并提示新增。

### 3.3 新增/编辑商品

```text
谷子图鉴 → 添加商品
  → 名称、作品、角色、主分类、板块、系列
  → 状态（想要/蹲价/预订/待补/已入手/取消）
  → 市场价 + 市场价日期
  → 实际购买价/购买日期/渠道（或关联订单）
  → 自定义字段
  → 图片（主图 + 多图）
  → 保存
```

编辑时：

- `revision` 乐观锁；冲突弹窗保留云端/覆盖；
- 修改市场价时可选「同步新增价格历史」；
- 修改状态写 `status_history`；
- 删除 = 软删除，进回收站。

### 3.4 分类管理

```text
设置 → 分类管理
  ├─ 20 内置：改名、上移/下移；不显示删除
  └─ 自定义：新增、改名、排序、删除
       删除 → 显示关联商品数
         → 选择目标分类（含「未分类」）
         → 批量更新 products.main_category_key
         → 软删除分类
```

生效范围：

- 商品新增/编辑下拉；
- 分类核对（待核对筛选）；
- 全图鉴导航；
- 商品详情/卡片标签；
- 首页分类进度；
- 报告的分类统计。

不混用：

- 主分类 = `main_category_key`；
- 独立板块 = `board_key + board_categories/assignments`；
- 分类核对 = `classification_status`，不是第三套分类表。

### 3.5 系列全收集清单

```text
谷子图鉴 → 系列清单 → 新建系列
  → 选择作品/角色（可选）
  → 添加清单项：关联已有商品 / 手工输入官方款
  → 标记：未拥有 / 想要 / 已预订 / 待补尾款 / 已拥有
  → 自动计算 已有/缺少/完成率
```

- 手工项不要求先建商品；可后续关联商品。
- 已拥有项优先取关联商品的状态，避免两套状态冲突。
- 未拥有显示灰色剪影；想要星标；预订/待补角标。

### 3.6 书籍套/卷

```text
书籍收藏 → 新建套书
  → 书名、类型、语言、出版社、版次、装帧、总卷数
  → 添加卷：卷号/卷名/ISBN/封面/价格/状态
  → 保存
  → 套书卡片显示 已拥有 8/12、完成率、缺卷
```

独立单本：

```text
书籍收藏 → 添加单本
  → 不选套书
  → 书名/作者/出版社/版次/ISBN/价格/状态
```

版本区分：

- 语言/出版社/版次/装帧不同 → 不同套书或不同单卷；
- 重复检测只提示，不自动合并；
- ISBN 相同但版本不同，仍允许保存。

### 3.7 订单/定金/尾款

```text
商品/书籍详情 → 关联订单
  → 新建订单：总额、运费、优惠、店铺、订单号、尾款截止
  → 添加付款：定金/尾款/运费/全款
  → 添加退款：退款金额/日期
  → 查看待补尾款
```

待补尾款页：

- 总待补、订单数、7 天内截止、逾期；
- 每笔订单展开付款明细；
- 补录付款/退款；
- 计算规则见 `04-付款与备份设计.md`。

### 3.8 自定义状态

```text
设置 → 状态管理
  → 新增：名称、颜色、图标（emoji 或上传）、排序
  → 编辑/排序
  → 删除：显示使用中的商品/书籍数量
      → 选择目标状态批量迁移，或取消
```

- 六默认状态保留，可改名/改色/改图标，不可删除；
- 自定义状态可删除；
- `counts_as_owned` 只允许「已入手」类状态为 true。

### 3.9 自定义字段

```text
设置 → 字段管理
  → 新增字段：名称、类型、必填、选项、排序
  → 商品/书籍编辑页动态渲染
  → 详情展示、搜索、备份
```

- 字段类型：单行/多行/数字/日期/单选/多选/URL/图片；
- 删除字段前提示已有值数量，确认后软删除定义 + 值；
- 图片字段存 Storage 路径，备份包含。

### 3.10 成就/徽章

```text
成就页 → 系统成就自动解锁
  → 自定义徽章：上传图、名称、描述、分类、规则/手动
  → 手动授予/取消
  → 主页展示获得时间
```

- 系统成就 `badge_type=system`，自动计算；
- 自定义徽章 `badge_type=custom`，可规则或手动；
- 手动授予的记录 `award_source=manual`，自动任务不得覆盖；
- 只统计 `counts_as_owned` 的收藏。

### 3.11 报告/海报

```text
报告 → 选月份/年份
  → 新增收藏、购入数量、实际支出、定金/尾款、分类、角色、系列
  → 书籍数量/卷数、心愿完成、增长趋势
  → 生成海报 → 下载 PNG
```

- 支出按 `payment_records.paid_at`；
- 退款冲减；
- 未收货预订不计入已拥有；
- 海报用 Canvas 绘制，支持保存图片。

### 3.12 重复检测

```text
更多 → 重复检测 → 扫描
  → 候选列表：商品图、编号、名称、系列、原因、相似度
  → 确认重复 / 忽略
  → 不自动删除、不自动合并
```

书籍额外比较 ISBN/书名/作者/出版社/版次/语言；版本不同只提示，不判定重复。

### 3.13 出物

```text
商品/书籍详情 → 出物
  → 闲置 / 待出 / 已出
  → 出售价格、日期、买家备注、交易备注
  → 保存
```

- 不删除原购买记录/收藏记录；
- 已出可标记 `sale_status=sold`，报表可统计回血；
- 是否从「当前拥有」移除由用户选择，默认保留历史但标记已出。

### 3.14 回收站

```text
删除 → 软删除 → 回收站
  → 恢复
  → 永久删除（二次确认 + 自动备份）
```

- 恢复父记录前先恢复父；
- 永久删除清理 Storage；
- 软删除记录默认进入备份。

### 3.15 备份/恢复

```text
账户 → 完整备份 → 选择是否含原始图 → 下载 ZIP
账户 → 恢复 → 选择 ZIP → 校验/预览 → 合并/覆盖 → 二次确认 → 报告
```

- 恢复前自动备份当前数据；
- 不静默覆盖；
- 缺失图片可忽略但报告；
- v2 备份兼容。

## 4. 分期开发计划

> 人天是「等效传统开发」估算；我是 AI 执行，实际日历时间会压缩，但验收/沟通/迁移执行仍需要你参与。

| 阶段 | 内容 | 人天 | Token | 验收 |
|---|---|---:|---:|---|
| P0 | 现状审计、ER、Migration 设计、页面流程、风险 | 2–3 | 250k–400k | 本文档确认 |
| P1 | 核心表 + RLS + 状态/字段/分类/地点/系列 + 软删除 + v4 备份骨架 | 7–10 | 900k–1.4M | 迁移可执行、1537 不变、RLS、配置 CRUD |
| P2 | 谷子完善：作品/角色 CRUD、分类管理、真角色筛选、系列清单 | 7–10 | 900k–1.4M | 验收 2–6 |
| P3 | 书籍：类型、套书、卷、版本、套书进度 | 6–9 | 800k–1.2M | 验收 7 |
| P4 | 状态、订单/定金/尾款/退款、价格历史、出物、待补页 | 7–10 | 900k–1.5M | 验收 8、11、12、13、17 |
| P5 | 成就/徽章、月报/年报/海报、重复检测、地点、相册、搜索 | 10–14 | 1.3M–2.2M | 验收 9、10、14、15、16、18、19 |
| P6 | 备份 v4/恢复、回收站、移动端、同步、23 项回归、部署 | 7–10 | 900k–1.5M | 验收 20–23 |
| **合计** | | **46–66** | **5.0M–8.2M** | |

> 这是完整 V6 的诚实范围。若只做「双类型 + 书籍卷 + 状态 + 尾款 + 备份」的 MVP，可压到 18–25 人天，但 23 项验收无法全过。

## 5. 每期验收标准

### P1

- 增量 Migration 在测试库可重复执行；
- 1537 条 `products`、20 主分类、347/77 板块计数不变；
- 新表 RLS：A 用户看不到 B 用户数据（用测试账号验证）；
- 状态/字段/分类/地点/系列定义可 CRUD 并跨设备读取；
- 软删除列存在，现有查询默认过滤；
- 备份 v4 能导出/读取空书籍数据，v2 备份仍可读取。

### P2

- 新增/编辑/删除作品、角色；删除有商品的角色被阻止；
- 全图鉴切换作品后角色列表联动；切换角色后商品列表真实过滤；
- 商品数量、分页、搜索、分类筛选随角色切换重置/重算；
- 20 内置分类改名/排序生效；自定义分类新增/编辑/排序/删除 + 重归类；
- 新分类出现在商品新增/编辑/核对/导航/详情；
- 系列清单可建、可加手工项、可关联商品、计算完成率；
- 首页与全图鉴当前角色一致。

### P3

- 书籍类型可新增/编辑/排序/删除；
- 套书可建，卷可增删改；独立单本可建；
- 8/12 进度、缺卷列表、完成率准确；
- 不同语言/出版社/版次/装帧不被合并；
- 套书删除不误删单卷；单卷删除保护关联订单/图片；
- 书籍跨设备同步。

### P4

- 六默认状态 + 自定义状态 CRUD/排序/删除重分配；
- 定金/尾款/运费/优惠/退款计算准确；
- 待补尾款页总额、订单数、即将截止、逾期正确；
- 市场价日期可空；旧数据不伪造；价格历史可查看；
- 出物记录保留原购买/收藏；
- 报告支出按付款日期，退款冲减。

### P5

- 系统成就自动解锁；自定义徽章图片上传/手动授予/取消；
- 手动徽章不被自动覆盖；获得时间保留；
- 月报/年报统计准确；海报可下载；
- 重复检测只提示，确认后手动处理；
- 地点层级/筛选；多图相册主图/删除/替换；
- 统一搜索覆盖谷子/书籍/自定义字段。

### P6

- 完整备份包含全部 V6 数据 + 图片；恢复后数据完整；
- v2 备份可恢复；
- 恢复前预览/确认，不静默覆盖；
- 回收站可恢复/永久删除；
- 电脑/手机布局正常；
- 23 项验收逐项通过；
- V5 原有功能回归通过。

## 6. 依赖顺序

```text
P1 数据模型/RLS/备份骨架
  ├─ P2 谷子（依赖作品/角色/分类/系列）
  ├─ P3 书籍（依赖状态/类型/系列）
  └─ P4 交易（依赖商品/书籍/状态）
        └─ P5 展示（依赖 P2/P3/P4 数据）
              └─ P6 备份/回收站/移动端/回归
```

不能先做报告/海报，再做付款流水；否则统计会返工。

## 7. 开发前检查点

1. 你确认本设计（尤其书籍模型、付款规则、软删除、备份 v4）；
2. 你完成一次 Supabase 完整备份（或确认云端只有初始 1537 条）；
3. 在 Supabase 测试项目/分支演练 Migration；
4. 代码打 tag `pre-v6-p1`；
5. 之后才进入 P1，不直接改线上。

## 本次审计的硬边界

- 只读审计：没有改动任何源代码、数据库表、数据、Storage 文件或 Migration。
- 没有执行任何 SQL 写入；没有删除或覆盖 1537 条商品。
- 线上参考数据已通过 Supabase REST 实际读取确认；用户私有表因 RLS 需要登录态，审计结论以实际 Migration + 代码为准，并在文档中标注了未能直接读取的部分。
- P0 完成后等待你确认，不自动进入 P1。

## 一句话结论

V6 不是「在 V5 上加几个字段」，而是要在**保留 `products` 原表和 1537 条数据**的前提下，新增一层通用收藏模型：书籍套/卷、状态、付款流水、自定义字段、系列清单、成就、相册、地点、软删除和备份 v4。

建议分 6 期开发；P0 之后先做 P1 基础模型，不能直接做页面。

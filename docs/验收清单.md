## 4. 已知限制

- 真实 Supabase 未在本环境联调；所有云端代码路径已实现，但上线前必须做一次账号/Storage/Realtime 验证。
- 完整备份包含原始图时约 41MB，手机端可能较慢；可取消“包含原始合集图”。
- 原始合集图在恢复时不会重新上传到 Storage，依赖项目 `assets/`；用户上传图会重新上传。
- Realtime 未开启时靠刷新/聚焦同步，不是实时推送。
- 浏览器可能拦截自动下载的迁移前 JSON 快照；本机 V4 数据不删除。
- 免费 Supabase 项目长期不活跃会暂停，恢复后数据仍在；生产建议 Pro + 平台备份。

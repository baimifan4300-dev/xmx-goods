星愿收藏室 · 夏鸣星谷子图鉴 v5 预览说明
========================================

一、本地预览（不需要 Supabase）
-------------------------------
1. 双击 start.bat（或 npm run dev）。
2. 浏览器打开 http://127.0.0.1:8765/?demo=1
3. 本地预览会从 data/gyly/xmx/products.json 初始化 1537 件商品，
   并读取本机 V4 的收藏、愿望、联动/满赠分类。
4. 数据只保存在当前浏览器，不会跨设备同步；页面顶部有明确提示。

二、云端模式（Supabase）
------------------------
1. 按 docs/云端部署与迁移.md 创建 Supabase 项目并执行三份 SQL。
2. 在 config.js 填写 SUPABASE_URL / SUPABASE_ANON_KEY，
   或在 Vercel 配置同名环境变量后重新部署。
3. 打开 http://127.0.0.1:8765/ 或线上域名，注册/登录。
4. 首次登录自动导入 1537 条商品，并迁移本机 V4 收藏/愿望/联动满赠分类。
5. 多设备登录同一账号即可共享数据。

三、主要功能
------------
- 全图鉴：搜索、20 主分类、联动/满赠、待核对、状态筛选、排序、分页。
- 商品详情：合集原图红框、高清图切换、市场价/购买价/数量/日期/备注。
- 商品管理：站内新增、编辑、删除；图片上传/替换/删除/恢复合集图。
- 收藏：数量可大于 1，购买价与市场价独立。
- 联动/满赠：新建、重命名、删除分类；删除分类不删除商品。
- 账户：完整备份 ZIP（含图片）、恢复备份、V4 收藏 JSON 导入导出、退出登录。
- 冲突：两台设备同时修改时弹窗选择保留版本，不静默覆盖。

四、测试命令
------------
npm run check
npm test
npm run test:db
npm run test:e2e
npm run test:full-backup

五、注意
--------
- 不要在前端使用 service_role key。
- 原始 data/gyly/xmx/products.json 不会被站内操作修改。
- 完整备份含个人购买信息，请妥善保管。
- 详细部署、数据库、备份说明见 docs/ 目录。
